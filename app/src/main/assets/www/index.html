Formats pris en charge et limites navigateur

Vidéo : HLS (.m3u8), DASH (.mpd), MP4 (H264/H265 selon navigateur), WebM (VP8/VP9/AV1), MOV, MKV (selon codecs), TS, AVI (lecture si codec supporté, sinon le fournisseur doit transmuxer). Très haute résolution 1080p, 2160p 4K et 8K si le flux et l'appareil suivent. Audio : AAC, MP3, Opus, Vorbis, FLAC, WAV, AC3/EAC3 (passthrough selon appareil). Pistes audio multiples et sous-titres WebVTT gérés quand le flux les expose. Si un flux ne démarre pas, c'est presque toujours un codec non supporté par le navigateur ou un blocage CORS/hotlink côté fournisseur : essayez le bouton Réessayer via proxy ou changez de qualité.

Astuce : vous pouvez coller directement votre URL complète (type get.php?username=... ou player_api.php?username=...) dans le champ serveur : l'identifiant et le mot de passe seront extraits automatiquement. Le journal ci-dessus détaille chaque tentative en cas d'échec.

Protocole Ministra : handshake, profil, liste des chaînes, create_link pour l'URL réelle. Si le portail bloque le CORS, changez de proxy dans Réglages. L'adresse MAC doit être autorisée côté fournisseur.
